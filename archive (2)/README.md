# Support Ticket Classification and Priority Prediction

## Project Overview
This project uses Machine Learning and Natural Language Processing (NLP) to automatically classify customer support tickets into different categories and predict their priority level.

## Features
- Text preprocessing using NLTK
- TF-IDF feature extraction
- Ticket category classification
- Ticket priority prediction
- Model evaluation using Accuracy, Precision, Recall, and F1-score
- Confusion Matrix visualization

## Technologies
- Python
- Pandas
- NLTK
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Dataset
Customer Support Ticket Dataset (Kaggle)

## Business Impact
This project helps organizations automatically organize customer support tickets, identify urgent issues, reduce manual effort, and improve customer response times.

- Use advanced NLP models such as BERT.
